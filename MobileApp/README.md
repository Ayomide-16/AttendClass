# AttendClass Mobile App 📱

The official React Native (Expo) companion for the AttendClass biometric ecosystem.

## ✨ Features
- **Strict Parity**: 1:1 functional translation of the AttendClass WebApp.
- **BLE Check-in**: Integrated Bluetooth Low Energy scanner for proximity verification.
- **Role-Based Access**: Specialized dashboards for Students, Lecturers, and Course Representatives.
- **Offline-Persistence**: Session management via Async Storage for reliable mobile use.

## 🛠 Tech Stack
- **Framework**: Expo (SDK 51)
- **Navigation**: Expo Router (v3)
- **Styling**: NativeWind (Tailwind CSS)
- **State Management**: TanStack Query (React Query)
- **Bluetooth**: react-native-ble-plx
- **Icons**: lucide-react-native

## 🚀 Development
```bash
npm install
npx expo start
```
